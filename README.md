## 평가 기준

모든 UI 항목을 아래 네 가지 기준으로 평가했습니다.

- **시인성 (Visibility)**: 핵심 메커니즘이 교전 중에도 정확히 인지되는가
- **행동 유도성 (Affordance)**: 형태와 시각 요소만으로 조작 방식을 유추할 수 있는가
- **정합성 (Accuracy)**: 원작의 핵심 경험을 유지하면서 불필요한 시각적 혼잡을 줄였는가
- **일관성 (Consistency)**: 영웅별 조작·스킬 설명 표기가 통일되어 있는가

## 개인 조사 파트

### 1. 인게임 정보 구조(IA)·유저 플로우 분석
- 영웅 선택, 메인 HUD, 전황판(Tab), 시스템 메뉴(Esc), 경기 종료 화면의 정보 구조 정리
- 매칭부터 로비 복귀까지 핵심 유저 플로우 8단계 정리
- 실시간 영웅 변경(카운터 픽) 루프, 경기 종료 후 POTG·추천 시퀀스를 UX 관점에서 분석

### 2. 탱커 영웅 HUD 분석
- 대상: 레킹볼, 윈스턴, 로드호그, 라마트라, 정커퀸, 둠피스트, 해저드, 스킬창, 스코어보드
- 스킬 설명과 실제 동작이 다른 부분 지적
  - 예: 윈스턴 방벽은 설명상 반구 형태지만, 공중에 설치하면 구 형태로 생성됨
- 숨겨진 조작 규칙 명시 제안
  - 예: 로드호그 숨돌리기의 재입력 취소 기능이 HUD에 안내되지 않음

## 팀 공동 작업

- 역할군·실력대가 다른 **가상 유저 페르소나 4명**을 설정한 시나리오 분석
- 개선 프로토타입 4종 (Before → After 시안)
  1. 영웅 정보창에 데미지·사거리·쿨타임 등 정량 수치 표기
  2. 전체 점수판을 열지 않고 아군 궁극기 현황을 보는 컴팩트 오버레이
  3. 조준 중 잔여 탄약·조준 상태 HUD 강화
  4. 무기 회수 가능 시점 인디케이터
- 영향도·시야 차단 정도에 따른 개선 우선순위 매트릭스

> 페르소나는 가상으로 설정한 인물이며, 실제 사용성 테스트(UT)는 진행하지 않았습니다. 사용성 테스트는 로드맵의 다음 단계로 계획되어 있습니다.
